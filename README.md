<h1 align="center">STORM CHRONICLES</h1>

## **О проекте**
STORM CHRONICLES — интерактивная графическая энциклопедия, таймлайн-менеджер и база знаний для документирования игровых вселенных, комплексных сюжетов, персонажей, фракций и хронологии событий. Позволяет визуализировать ветвящиеся сюжетные линии, канонические события и взаимосвязи персонажей.

## **Происхождение и форки**
Оригинальная разработка в рамках экосистемы STORM SOFT.

## **Технологический стек**
- **Языки программирования**: TypeScript, JavaScript (Node.js)
- **Интерфейс**: React 18, Tailwind CSS, Lucide Icons, Vite
- **Графы и диаграммы**: React Flow / Cytoscape.js, D3.js
- **Хранилище данных**: SQLite / IndexedDB с поддержкой JSON-схем

## **Ключевые возможности**
- **Интерактивные временные шкалы**: Создание многоуровневых масштабируемых таймлайнов с фильтрацией по эпохам, персонажам и локациям.
- **Графы взаимосвязей**: Визуализация древа отношений персонажей, фракций и сюжетных линий.
- **База знаний и вики**: Встроенный Markdown-редактор с перекрестными ссылками и медиа-галереей.
- **Импорт и экспорт**: Сохранение базы в JSON, Markdown, PDF и полная автономная работа.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows, Linux, macOS, современные веб-браузеры

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_CHRONICLES_<версия>_Setup.exe` или архив `STORM_CHRONICLES_<версия>.zip` из раздела **Releases**.
2. Установите приложение или запустите веб-версию в соответствии с инструкциями в дистрибутиве.

## **Безопасность и цифровые подписи**
Сборки подписаны сертификатом **CN=STORM SOFT, O=STORM EDEN** (SHA-256 Authenticode).
